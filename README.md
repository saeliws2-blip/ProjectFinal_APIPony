8.2 ตารางข้อแนะนำจากงานแรก → สิ่งที่แก้
|ข้อแนะนำจากงานแรก|สิ่งที่แก้ในงานนี้|หลักฐาน Before / After|
|ควรปรับแก้ไข้ sort ให้ผลลัพธ์ออกมาตรงเมื่อกดเลือก season |ให้ backend จัดเรียงข้อมูล และนับจำนวนตอนใส่ไว้ในข้อมูลตั้งแต่แรก และเมื่อส่งข้อมูลมาให้ frontend ข้อมูลจะตรงกับ API เมื่อสั่ง sort เสมอ|เมื่อกด sort เลือก season แล้วข้อมูลของตัวละครจะตรงกับ season ที่เลือกเอาไว้|
|ควรปรับแก้ไข้ sort ให้ผลลัพธ์ออกมาตรงเมื่อกดเลือก A-Z|แยกวิธีเรียงตัวอักษรและตัวเลขให้ชัดเจน โดยตัวอักษรใช้ localeCompare() (เรียงตามพจนานุกรม) และตัวเลขใช้ Season ใช้เรียงแบบตัวเลข (a, b) => a - b|เมื่อกดเลือก sort เรียงชื่อ A-Z แล้ว ตัวละครจะขึ้นเรียงชื่อตั้งแต่ A-Z|
|แก้ไขข้อมูลตัวละคร|ปรับเปลี่ยนเป็นเกมแนว Turn-based แทน โดยใช้โครงสร้างข้อมูลแบบ Queue Data Structure บน frontend ตัวละครไหนออกไปสู้แล้ว จะถูกเอาออกจากคิว(Dequeue)ทันที ทำให้หน้าจอไม่เกิดข้อมูลตัวละครซ้ำ รวมถึงเพิ่มลูกเล่นความน่าสนใจให้กับเว็บ||
|UX ไม่มีความน่าสนใจและเป็นระเบียบ|จัดระเบียบ Control Panel ด้านบนสุดให้มีช่องค้นหา ช่องกรอกซีซัน และปุ่มควบคุมที่ใช้งานง่าย พร้อมใส่ระบบ Focus Border สีพาสเทลเพื่อให้ผู้ใช้งานรู้ว่ากำลังใช้งานช่องไหนอยู่ และเพิ่มระบบจัดการสถานะครบถ้วนทั้ง loading, success, empty และ error พร้อมปุ่ม retry ทันที่ที่เชื่อมกับ API ไม่สำเร็จ|หน้า UX มีความน่าสนใจและเป็นระเบียบมากยิ่งขึ้นจากตอนแรกที่ดูไม่น่าสนใจ|
|หน้าเลือกตัวละครมีตัวละครให้เลือกมากเกินไปและการกรอง season เฉพาะตัวละครในseasonนั้น|ทำ Pagination ผ่าน Component pager จำกัดการแสดงผลเหลือเพียง 20 ตัวจ่อหน้า ร่วมกับฟีเจอร์ Season Filtering เมื่อผู้เลือกใช้เลือก season ไหนระบบจะแสดงผลเฉพาะตัวละครใน season นั้น ตัวละครที่ไม่เกี่ยวข้องจะถูกคัดออกทันที ทำให้ flow หลักสั้นลง|หน้าเลือกตัวละครมีเพียง 20 ตัวละครต่อหน้า และมีเพียงตัวละครที่กำหนดไว้ใน season นั้นๆ ตัวละครที่ไม่เกี่ยวข้องจะไม่ถูกแสดงขึ้นมา|

8.3 ตาราง useState
|ชื่อ state|เก็บข้อมูลอะไร|อยู่ใน component|เปลี่ยนค่าเมื่อใด /โดยใคร|ทำไมต้องเป็นstate|
|all|ข้อมูลตัวละครทั้งหมดจาก API หลังแปลงข้อมูลและคำนวณค่าเพิ่ม|GameProvider|เมื่อโหลดข้อมูลจาก API สำเร็จ|ให้ทุกส่วนของแอปใช้ข้อมูลตัวละครชุดเดียวกัน และ render ใหม่เมื่อข้อมูลเปลี่ยน|
|loading|สถานะกำลังโหลดข้อมูลตัวละคร|GameProvider|เริ่มโหลดและเมื่อการโหลดเสร็จ|ให้หน้าเว็บแสดงสถานะกำลังโหลด|
|error|ข้อความเมื่อโหลดข้อมูลไม่สำเร็จ|GameProvider|ล้างก่อนโหลด และกำหนดเมื่อเกิดข้อผิดพลาด|ให้หน้าเว็บแสดง error และให้ผู้ใช้ลองโหลดใหม่|
|team|รหัสตัวละครที่ผู้ใช้เลือกเข้าทีม ไม่เกิน 3 ตัว|GameProvider|เมื่อเพิ่ม/นำตัวละครออก ล้างทีม หรือกรองรหัสที่ไม่มีในข้อมูล|ให้หน้าตัวละคร ทีม และต่อสู้ใช้ทีมชุดเดียวกัน|
|enemyIds|รหัสตัวละครที่ถูกเลือกเป็นศัตรู|GameProvider|เมื่อสุ่มศัตรูหรือสุ่มใหม่ผ่าน ensureEnemies|ใช้จัดทีมศัตรูสำหรับการต่อสู้|
|query|คำค้นหาชื่อตัวละครหรือฉายา|CharactersPagePony|ผู้ใช้พิมพ์หรือล้างคำค้นหา|ให้รายการตัวละครกรองตามคำค้นหา|
|sort|รูปแบบการเรียงตัวละคร|CharactersPagePony|ผู้ใช้เลือกรูปแบบเรียง เช่น A-Z, จำนวนตอน หรือระดับดาว|ให้รายการแสดงตามรูปแบบที่เลือก|
|season|ซีซันที่ใช้กรองตัวละคร|CharactersPagePony|ผู้ใช้เลือกซีซันหรือล้างตัวกรอง|ให้รายการแสดงตัวละครเฉพาะซีซันที่เลือก|
|page|หน้าปัจจุบันของรายการตัวละคร|CharactersPagePony|ผู้ใช้เปลี่ยนหน้า หรือเปลี่ยนตัวกรองแล้วระบบกลับไปหน้าแรก|ควบคุมรายการที่แสดงใน pagination|
|open|ตัวละครที่เปิดดูใน modal หรือ null เมื่อปิด|CharactersPagePony|ผู้ใช้เปิดการ์ดหรือปิด modal|ควบคุมการเปิด/ปิดรายละเอียดโดยไม่เปลี่ยนหน้า|

|showLog|สถานะเปิดหรือซ่อนบันทึกการต่อสู้|BattlePage|ผู้ใช้กดปุ่มดู/ซ่อนบันทึก|ควบคุมการแสดง battle log|

|departed|สถานะว่าการ์ดนักสู้ที่ HP หมดควรถูกนำออกจากจอแล้วหรือยัง|UnitCard|ตั้งหลัง HP หมด 1.05 วินาที และ reset เมื่อ HP มากกว่า 0|ให้แสดงสถานะพ่ายแพ้ก่อนนำการ์ดออกจากจอ|
