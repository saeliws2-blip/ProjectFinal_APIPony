# Pony Cards
เว็บแอปสะสมการ์ดตัวละครจาก My Little Pony ผู้ใช้สามารถค้นหาและเลือกตัวละครเพื่อจัดทีม แล้วนำทีมไปต่อสู้กับศัตรูในรูปแบบ Turn-based

## ฟีเจอร์หลัก
- ค้นหา กรองตามซีซัน และเรียงลำดับตัวละคร
- แสดงตัวละครแบบแบ่งหน้า หน้าละ 20 ตัว
- ดูรายละเอียดตัวละครและเลือกสมาชิกเข้าทีมได้สูงสุด 3 ตัว
- ต่อสู้แบบ Turn-based พร้อมสุ่มทีมศัตรู
- บันทึกทีมที่เลือกไว้ในเบราว์เซอร์

## API ที่ใช้
- [Pony API](https://ponyapi.net/)

## เทคโนโลยีที่ใช้
- Frontend: React, Vite และ React Router
- Backend: Node.js และ Express
- ข้อมูลตัวละครและตอน: [Pony API](https://ponyapi.net/)

## วิธีติดตั้งและรันในเครื่อง

ต้องติดตั้ง Node.js และ npm ก่อน จากนั้นเปิด Terminal แยก 2 หน้าต่าง

Terminal ที่ 1 — รัน Backend:

```bash
cd backend
npm install
npm run dev
```

Backend จะทำงานที่ `http://localhost:3000`

Terminal ที่ 2 — รัน Frontend:

```bash
cd frontend
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal (โดยปกติคือ `http://localhost:5173`)

## Deploy บน Vercel และ Render

## แหล่งข้อมูล

Backend โหลดข้อมูลจาก Pony API แล้วให้ Frontend เรียกใช้งานผ่าน endpoint ต่อไปนี้:
- `GET /characters` — โหลดรายการตัวละคร
- `POST /characters/reload` — โหลดข้อมูลตัวละครและตอนใหม่
- `GET /characters/:id` — โหลดข้อมูลตัวละครตาม ID

เมื่อต้องการเรียก Backend ที่ deploy แล้ว Frontend ใช้ `https://projectlpony-backend.onrender.com`
